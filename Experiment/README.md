# Experiment

This folder contains MATLAB code and choke valve degradation data for experiment of stochastic identification by IMM-SMC algorithm of the degradation process.

## Files

* **`PFExp.m`**: Main MATLAB script for loading the choke valve data and running the identification experiment.
* **`CV1Data.xlsx`**: Pre-processed degradation data of a choke valve degradation over a period exceeding one year.

## Data Information

* The raw operational data from the production choke valve cannot be publicly shared due to confidentiality requirements related to the field and its operating conditions. The repository therefore provides the preprocessed data and extracted true degradation data used in the experiments.
* The data from the second choke valve is subject to separate data-sharing restrictions and is therefore not permitted to be released as open-source data in this repository.
